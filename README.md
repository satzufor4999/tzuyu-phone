# Tzuyu's iPhone 📱

互动式 iPhone 模拟网页，包含虚构 TWICE 日常剧情、相册与模拟相机。

> Fan-made fiction. Not an official TWICE/JYP project. All simulated private messages and stories are fictional.

## 发布

1. 解压 ChatGPT 中的 **tzuyu-phone-github-ready.zip**。
2. 在仓库的 **Add file → Upload files** 上传解压后文件夹**内部**的 `index.html`、`assets/` 文件夹、`.nojekyll` 等；不要上传 ZIP，也不要嵌套多一层目录。
3. 在 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，设置 `main` / `/(root)`，然后 Save。
4. 访问 https://satzufor4999.github.io/tzuyu-phone/ 。

提醒：GitHub Pages 是公开网站。游戏解锁码不是访问权限保护。
